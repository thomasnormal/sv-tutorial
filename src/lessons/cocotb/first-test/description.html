cocotb (Coroutine-based Co-simulation Testbench) is an alternative to UVM: write your testbench in Python rather than SystemVerilog. The simulator runs your DUT exactly as before; Python drives signals and checks outputs through an async coroutine.

A test is any async function decorated with @cocotb.test(). The dut argument gives you handles to every port — assign .value to drive, read .value to observe. The helper enters ReadWrite before driving, waits with await Timer(1, units="ns"), then enters ReadOnly to sample the settled combinational result.
