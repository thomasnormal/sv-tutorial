An SRAM address bus is a packed vector because its bits travel together. A table of words is an unpacked array because each word is a separate element. Those two brackets mean different things, and confusing them can silently change how indexing and storage work.

The pattern

A packed dimension appears before the variable name; an unpacked dimension appears after it:

logic [W-1:0] packed_word;       // one W-bit vector
logic [W-1:0] memory [0:D-1];   // D separate W-bit elements
logic [L-1:0][W-1:0] lanes;     // L packed lanes, W bits each

Packed dimensions form one contiguous bit-vector. You can concatenate or assign the whole value at once. Unpacked dimensions form an array of elements; indexing selects one element. The system function $size(array) reports one dimension without repeating a magic number. The related $dimensions(array) function counts all dimensions; this exercise focuses on $size.

Two bracket positions

In logic [7:0] mem [0:3], mem[2] is an 8-bit word and $size(mem) is 4. In logic [1:0][3:0] lanes, the whole object is an 8-bit packed value and $size(lanes) reports the first packed dimension, 2.
