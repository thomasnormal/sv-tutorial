The SRAM controller constantly combines address, data, and control bits. The one new idea here is a continuous assign: it keeps a relationship live as a wire, so an output follows its inputs immediately without a clock or storage. The bitwise, reduction, ternary, and arithmetic expressions below are different values you can place on that same always-connected path.

The pattern

Start with the general form. A continuous assignment drives one output from an expression whenever any value in that expression changes:

assign <output> = <expression>;

For a vector, the operator works bit by bit; for a reduction, the operator collapses the whole vector to one bit; and a ternary chooses between two complete values:

assign bits  = left & right;       // bitwise
assign ready = |requests;           // reduction OR
assign data  = select ? a : b;      // conditional choice

Expressions on a live connection

Bitwise & and | preserve a vector's width. A reduction |a combines every bit of a into one result, useful for a “any request?” flag. The ternary condition ? when_true : when_false is a compact 2:1 multiplexer.

What the live expression preserves

Arithmetic does not magically grow to hold a carry. The 4-bit values 4'b1010 and 4'b0110 add to 16, but a 4-bit destination keeps only 4'b0000. Widening both operands first with {1'b0, a} preserves the carry in a 5-bit result. That is overflow: the mathematical answer exists, but the chosen width cannot represent it.

Signed vectors use two's-complement interpretation. The same four bits can mean a different number depending on the declaration: logic [3:0] is unsigned, while logic signed [3:0] lets 4'b1101 mean -3. Keep the signed declaration on both operands when adding signed values.

Testbench

The starter testbench prints every derived value, checks the truncated and widened sums separately, flips the ternary selector, and prints PASS only when all checks match. The waveform gives the same idea a second form: inputs and each continuously driven output change without a clock edge.
