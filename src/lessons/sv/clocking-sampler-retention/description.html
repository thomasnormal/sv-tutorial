A clocking block gives a testbench a named clock event and a sampled view of its input signals. The input skew controls when each signal is sampled relative to that event.

Exercise

Add an explicit #0 input skew to cb.sig. The testbench writes BB in an Active-region process, then writes CC after the clocking event has published its sample. The correct solution observes BB at the first event, keeps that sampled value through the same time slot and the following negedge, and samples BB again at the next positive edge.

clocking cb @(posedge clk);
  input #0 sig;
endclocking

Without an explicit input skew, the default is 1step, so the input is sampled immediately before the corresponding clock edge. With an explicit #0, the input is sampled in the Observed region. The clocking-block event is triggered after the sampled values are updated, and a clocking input keeps the value from its most recent clocking event.

IEEE 1800-2023 §14.3 defines the default 1step input skew. §14.4 defines sampling relative to the clock event and specifies that an explicit #0 input skew samples in the Observed region. §14.13 specifies that the updated sampled values are available before the clocking-block event triggers and that a #0 input is not resampled during same-slot Active re-entry unless a new clocking event occurs.

Open clocking_sampler.sv and add the skew. The passing solution prints PASS: clocking sample retained=bb.
