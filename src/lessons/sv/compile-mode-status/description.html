What a refusal means

Compile mode refuses before simulation when its AOT obligations cannot be satisfied. It does not silently fall back to interpretation. The current census vocabulary classifies the result:

StatusMeaning
AGREECompile passes, parity matches the frozen interpreter oracle, and the AOT counters are clean.
HELDThe compile stage refuses with the same recorded provider-dirty or mandatory-retain facts as the census.
HELD-CHANGEDThe same stage refuses, but its refusal details changed.
NEW-REFUSALThe refusal occurs at a stage different from the ledger.
DIVERGECompilation reaches simulation, but the verdict or observable output differs.
ORACLE-DRIFTThe interpreter result differs from the frozen oracle; stop instead of blaming AOT.
