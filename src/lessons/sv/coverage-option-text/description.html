A covergroup instance has instance-specific options. The comment option defaults to the empty string, and a procedural assignment can replace it for that instance.

Template

covergroup coverage_model;
  cp_value: coverpoint value;
endgroup
coverage_model coverage = new;
coverage.option.comment = "runtime coverage comment";

Complete the starter so it accepts the default empty comment and then assigns the requested runtime comment. The test samples one value before printing the result; the assignment is intentionally not checked by parsing simulator-specific coverage-report text.

IEEE 1800-2023 §19.7 and Table 19-1 define instance-specific coverage options. The comment option defaults to "", is saved with the covergroup instance, and may be assigned procedurally after instantiation.

The example is qualified against Mox landing commit b481355f9fe, which preserves valid unset coverage option strings before converting them to runtime strings. The pinned browser WASM is not treated as native AOT evidence.
