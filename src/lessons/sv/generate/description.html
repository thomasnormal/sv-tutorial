An SRAM data path may be 8, 32, or 64 bits wide, but the same one-bit operation repeats across every lane. Writing each copy by hand makes width changes risky. Generate constructs let elaboration choose optional hardware and replicate a regular piece before simulation starts.

The pattern

A generate loop has a compile-time index and creates one instance or assignment per index:

generate
  for (genvar i = 0; i < N; i++) begin : <lane_name>
    <one_lane_logic>
  end
endgenerate

A generate conditional selects one structure from a parameter. The condition is decided during elaboration, so the unused branch does not exist in the circuit:

if (<parameter_condition>) begin : <fast_path>
  ...
end else begin : <fallback_path>
  ...
end

genvar is a loop index for elaboration, rather than a signal that changes during simulation. The names after begin : give generated scopes stable, readable names in waveforms and diagnostics.

Replicate a lane

Exercise

Open generate_lab.sv. Add a named generate-if with an XOR branch and an OR branch. In each branch, add a generate-for loop from 0 through WIDTH-1 and drive the corresponding bit of y. The parameter USE_XOR selects which hardware exists, while WIDTH controls how many lanes are emitted.

Testbench

The testbench instantiates the same module three ways: four-bit XOR, four-bit OR, and eight-bit XOR. It applies one vector to all instances and checks each generated result. Changing a parameter changes the elaborated structure without changing the module body.
