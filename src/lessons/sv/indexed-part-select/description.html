An indexed part-select chooses a fixed-width slice from a run-time base index. The +: width form starts at the base and counts upward through the packed vector.

Template

<vector>[<base> +: <constant width>]
<vector>[<base> -: <constant width>]

The first check uses a run-time base and selects four bits entirely inside the vector. The second selection is completely outside the declared range, so the four-state result is unknown. Keeping the example to these unambiguous cases makes the lesson agree across Mox and Xcelium while the rule remains visible.

IEEE 1800-2023 §11.5.1 defines indexed part-selects and requires a positive constant width. A completely out-of-range read returns x; a partially out-of-range read returns x only for its out-of-range bits.
