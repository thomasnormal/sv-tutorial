A text macro can span several source lines when each continued line ends with a backslash. The preprocessor removes the backslash-newline pair before the compiler sees the declaration.

Template

`define <name>(<formal>) \
  <expanded text using <formal>>

In this example the macro emits a function declaration. The `` token-paste operator joins the macro argument to the function name, so `DECLARE_SUM(4) creates sum4. The formal argument list itself is split across continued lines.

Change the function body in macro_formal.sv so the generated function adds its two arguments. The testbench calls the generated function with its default arguments and prints PASS only when the expansion is correct.

IEEE 1800-2023 §22.5.1 defines text-macro substitution and says a backslash immediately before a newline continues macro text onto the next line. This is preprocessing, not a run-time function call.
