A memory controller often needs to answer a request as soon as it sees one. A Mealy FSM makes an output depend on both the current state and an input, so a request can assert grant before the next clock edge. That saves a cycle, but the output can also change whenever the input changes.

The pattern

typedef enum logic { <STATE_A>, <STATE_B> } state_t;
state_t state;

always_ff @(posedge clk) begin
  if (!rst_n) state <= <STATE_A>;
  else if (<input>) state <= <STATE_B>;
end

assign <mealy_output> = (state == <STATE_A>) && <input>;

The state is stored on the clock edge. The output expression is separate and combinational: it can see the current input immediately. This compact style keeps one procedural block for state and uses direct assignments for the outputs.
