Module inputs are live connections from the parent. When a child publishes a value, another child reached through a nested module must see that value before its clocked process samples it.

Template

module <source>(input logic clk, output logic <signal>);
    always @(negedge clk) <signal> <= <value>;
endmodule

module <sink>(input logic clk, input logic <signal>);
    always @(posedge clk) <check the input>;
endmodule

The source raises valid on a falling edge. The direct sink, a sink behind a wire wrapper, and a sink behind an output bridge all sample the same value on the following rising edge. The testbench counts four successful samples.

IEEE 1800-2023 §23.2.2 describes module port connections; a child input is driven by its connected parent expression. The clocked behavior uses procedural timing from §9.4.2.
