A sequential user-defined primitive (UDP) stores its current state in the output reg. An optional initializer gives that state a known value at time zero, before later input transitions use the table.

Template

primitive <name>(output reg q = 1'b1, input clk, input d);
    table
        (01) 0 : ? : 0;
        (01) 1 : ? : 1;
        (10) ? : ? : -;
    endtable
endprimitive

The starter gives the UDP the wrong initial value. Add the correct initializer so the testbench observes q=1 before the first clock edge and q=0 after a rising edge with d=0.

IEEE 1800-2023 §29.3.2 permits a constant initializer on an ANSI UDP output declaration. §29.6 defines edge-sensitive sequential UDP tables, and §29.7 makes sequential-UDP initialization optional and limits the procedural form to a single one-bit assignment. At simulation start, that value is the UDP's current state.
