A burst interface can move one bit at a time across a narrow pin or test link. A shift register stores the bits already seen, moves them one position per clock, and exposes the bit that is leaving. The same pattern appears in serial links, scan chains, and small delay lines.

The pattern

For a serial register of width N, the usual clocked shape is:

always_ff @(posedge <clk>) begin
  if (<reset_is_active>)
    <state> <= '0;
  else begin
    <serial_out> <= <state>[N-1];
    <state>      <= {<state>[N-2:0], <serial_in>};
  end
end

The concatenation has the old lower bits on the left and the new serial bit on the right. Every rising edge therefore shifts the stored pattern toward the most-significant bit.

Watch one bit travel

{a, b} is a concatenation: it joins the bits of a and b into one vector. Because non-blocking assignments read the old right-hand side before updating the left-hand side, serial_out <= q[3] captures the bit leaving while q <= {q[2:0], serial_in} advances the register.

Testbench

Each check waits for a rising edge and samples one time unit later, after the non-blocking update has settled. The printed state shows the incoming bits filling the register, then the flush phase showing each old MSB on serial_out. The waveform gives the movement a second view.
