A packed struct is one vector with named slices. That makes it useful at module boundaries: a child can read one field while the parent drives the complete value.

Template

typedef struct packed {
    logic [N:0] <field>;
    logic [M:0] <field>;
} <name>_t;

module <child>(input <name>_t src);
    assign <output> = src.<field>;
endmodule

The driver reads only exp_bits from the packed struct and drives that field on the destination struct. The testbench changes the source field and checks the connected field after one time step.

IEEE 1800-2023 §7.2.1 says a packed struct is treated as one vector, with the first declared member as the most-significant member. Its members can still be selected by name.
