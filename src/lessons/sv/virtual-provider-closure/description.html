A handle declared as a base-class type can refer to an object of a derived class. When the method is virtual, calling it through the base handle selects the latest derived implementation at run time.

Template

class base;
  virtual function int f();
    return 1;
  endfunction
endclass

class derived extends base;
  virtual function int f();
    return 7;
  endfunction
endclass

base value = new derived();
value.f();  // calls derived::f()

The starter's override returns the wrong value and records the wrong implementation ID. Fix both values so the call through base value observes the derived provider and prints PASS.

IEEE 1800-2023 §8.20 defines virtual methods and their overriding rules. §8.22 says a superclass variable may hold a subclass object and that a virtual call selects the appropriate subclass method at run time.
