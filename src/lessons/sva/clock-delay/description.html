The clock delay operator ## is what makes sequence expressions temporal. It shifts evaluation forward by one or more clock cycles.

  • ##m — exactly m cycles later
  • ##[m:n] — between m and n cycles later
  • ##[1:$] — one or more cycles ($ means unbounded)

Open delay_check.sv. The spec is: after a memory request (mem_req), the response (mem_ack) must arrive within 2 to 5 clock cycles.

The previous sequence lesson named multi-cycle patterns; here the delay itself is the rule. Complete the one-sample delayed_ack sequence, use |-> ##[2:5] in the property, and add its assertion before pressing verify.

The starter includes tb.sv with an acknowledgement at the earliest legal edge. Run it before solving to see the trace; after solving, the same trace checks the expected edge and prints PASS. Verify still searches unconstrained requests and acknowledgements for an off-by-one counterexample.

If the delay range is wrong, the Verify log reports COUNTEREXAMPLE FOUND and lists the model's signal assignments. BMC does not generate a Waves tab; use those assignments to spot off-by-one errors.
