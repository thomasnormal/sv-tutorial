A bus-hold rule often appears in several assertions: while a transfer is valid but not accepted, the payload must stay unchanged. Copying that Boolean expression into every property makes maintenance risky. A let declaration gives the expression one name and lets each property pass the signals it wants to inspect.

The pattern

let <rule>(<value>, <active>, <accepted>) =
  !(<active> && !<accepted>) || $stable(<value>);

property <check>;
  @(posedge clk) <rule>(data, valid, ready);
endproperty

let is scoped to the surrounding module or package and takes formal arguments like a small property macro. It keeps the intent named and typed by the context, without textual substitution or a second module instance.
