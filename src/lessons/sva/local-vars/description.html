A local variable in a sequence captures a signal's value at one clock edge and carries it forward to a later comparison — something you cannot do with plain signal references:

The comma operator (cond, v = expr) simultaneously checks the trigger condition and captures a value into the local variable. On a later cycle, compare the captured value to another signal:

(trigger, v = signal) |=> ##N (other == v)

Open pipeline_check.sv. Capture in_data when valid_in is high, then verify that out_data equals it exactly 3 cycles later.

The clock-delay lesson counted edges; this lesson carries the value across them. The starter includes tb.sv with one input transaction and its delayed output. Run it before solving to see the captured value travel; after solving, the trace prints PASS. Verify also checks overlapping transactions independently because each evaluation owns its local variable.

Local variables are thread-local: every concurrent evaluation of the sequence gets its own copy, so overlapping in-flight transactions are checked independently.
