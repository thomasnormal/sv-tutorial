A shared bus needs one owner at a time. If two requesters receive a grant, both can drive the bus and the failure may only appear as corrupted data much later. The arbiter's four-bit grant vector is an ownership token, so we can check its shape at every clock edge.

SystemVerilog provides built-in functions for checking these bit-count invariants:

  • $onehot(v) — true when exactly one bit of v is 1
  • $onehot0(v) — true when zero or one bits are 1
  • $countones(v) — returns the number of set bits; use in expressions like $countones(v) <= 2

Open arbiter_check.sv and add two properties:

  1. grant_onehot_p: whenever any_grant is high, grant must be one-hot — use $onehot(grant)
  2. grant_idle_p: whenever any_grant is low, grant must be all zeros

This reuses the request/grant timing pattern from sva/concurrent-sim, but adds a structural invariant to the grant bus. The starter includes tb.sv with two legal grants and an idle cycle. Run it first to see the trace; after solving, the same trace prints PASS and the signal timeline makes the single-owner rule visible.

|req is a reduction OR: it is 1 if any bit of req is 1. It is often used as a shorthand antecedent: |req |-> $onehot0(gnt) means "when any request is active, at most one grant is given."
