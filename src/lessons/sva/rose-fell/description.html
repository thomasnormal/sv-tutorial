Sampled value functions compare a signal's value at the current clock edge against the previous one:

  • $rose(sig) — true when sig just transitioned 0→1
  • $fell(sig) — true when sig just transitioned 1→0

These are more precise than a bare level check: $rose(req) triggers once per rising edge, not on every cycle that req stays high.

Open edge_check.sv. The spec is: when chip-select cs_n falls (goes active-low), ack must rise within 1–2 clock cycles.

Complete the one-sample ack_rise sequence, then use $fell(cs_n) |=> ##[0:1] ack_rise and assert the property. The non-overlapping implication starts checking after the falling edge, so the range covers the first and second response cycles.

The starter includes tb.sv with one active-low chip-select transition and an acknowledgement rising on the first legal response edge. Run it before solving to see the sampled edges; after solving, the same trace checks the edge and prints PASS. Verify explores unconstrained transitions to find an acknowledgement that arrives too early or too late.

When an assertion fails, the Verify log reports COUNTEREXAMPLE FOUND and lists the model's signal assignments. BMC does not generate a Waves tab.
