Two more sampled value functions for tracking signal history:

  • $stable(sig) — true when sig did not change between the previous and current clock edge
  • $past(sig) — the value of sig from exactly 1 cycle ago; $past(sig, n) goes back n cycles

Open stable_check.sv. The spec is: while valid is high and ready is low, data must not change on the next cycle. Complete the property body with the sampled-value functions.

This follows the concurrent-assertion sampling model from the earlier simulation lesson: the antecedent is sampled at one edge, then $stable(data) compares that edge with $past(data) at the next. The starter includes tb.sv with a stalled transfer that holds data, then changes it only after ready rises. Run it before solving to see the history; after solving, the trace prints PASS. Verify searches for a data change during a stall.

$stable(data) compares sampled four-state values. For an explicit equivalent, use data === $past(data); case equality keeps an X-to-X or Z-to-Z comparison stable, unlike == (IEEE 1800-2023 §16.9.3).
